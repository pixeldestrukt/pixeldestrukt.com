## What it does

Takes sACN over ethernet or WiFi and emits DMX512 on two isolated universes,
with break timing generated by hardware rather than by a loop that WiFi can
interrupt.

## Design notes

- **Hardware-timed break.** The UART generates break and mark-after-break, so
  radio activity cannot smear the frame. See the
  [DMX timing note](/notes/esp32-dmx-timing/) for the detail.
- **Isolated transceiver** on each output. Ground potential differences between
  racks are real.
- **Wired first.** Ethernet is the primary transport; WiFi is the fallback, not
  the plan.
- **Config is a file.** A JSON file on the device, editable over HTTP. Universe
  patch, static IP, failover behaviour. No wizard.
- **Defined failure mode.** On signal loss it holds last-look for a configurable
  timeout, then fades to a stored scene. It never snaps to black mid-show.

## Status

Working prototype on the bench, two revisions in. Enclosure and the last 10% of
the config surface are outstanding.
